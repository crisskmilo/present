- (source) Fuentes oficiales revisadas: Google Antigravity agent, Gemini pricing y Gemini API terms; GitHub Copilot plans; OpenRouter models, terms y privacy. Accedidas 2026-08-20.
- (claim) ref=[1] status=verified class=integration pub=2026-08 — Antigravity soporta ejecución de código, gestión de archivos, web, MCP y personalización con AGENTS.md/.agents/skills.
- (claim) ref=[1][5] status=verified class=pricing pub=2026-08 — La cuota gratuita de Gemini/Antigravity tiene límites de tasa y uso sujetos a cambios; las interacciones agénticas pueden consumir múltiples ciclos y admiten max_total_tokens.
- (claim) ref=[4][6] status=verified class=privacy pub=2026-08 — Los servicios gratuitos pueden usar entradas y salidas para mejora; OpenRouter transmite entradas al proveedor elegido y las prácticas de entrenamiento dependen del modelo.
